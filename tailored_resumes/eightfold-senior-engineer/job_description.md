## About the Data Platform Team

Responsible for the complete data life cycle management:
- Ingesting data from different external systems
- Normalizing data to a common data model
- Keeping data updated
- Archiving data as needed
- Auditing to check health of the platform
- Providing REST API access to data

Past projects: generic framework to sync millions of records from various systems; framework to identify and automatically fix data inconsistencies between different storage systems.
