## Overview
In Microsoft 365 Copilot, Copilot Search brings together email, files, chats, meetings, and people to compose a grounded AI answer with trusted citations alongside deep search results at global scale.

## Responsibilities
- Design, build, and ship Copilot Search features end-to-end in React and TypeScript, from design review through experimentation and worldwide rollout.
- Build performant, accessible, localized UIs across web, desktop, mobile hosts, SharePoint, and OneDrive.
- Drive web performance through SSR, hydration and rendering optimization, early data fetching, service workers, and bundle-size reduction (end-to-end latency and time to first answer).
- Integrate AI-generated answers into search (streaming responses, citations/source attribution, graceful handling of partial/failed responses).
- Instrument telemetry, define success metrics, run A/B experiments and staged rollouts.
- Own reliability: monitoring, alerting, automated health checks, diagnosis of authentication/host-loading failures, and on-call incident mitigation.
- Partner with PMs, designers, and backend search/relevance engineers; lead code reviews, automated testing, shared components, and AI-assisted development/quality evaluation.

## Minimum Qualifications
- Bachelor's Degree in CS or related technical field AND 4+ years technical engineering experience with coding in C, C++, C#, Java, JavaScript, or Python (or equivalent experience).

## Preferred Qualifications
- React and TypeScript production web applications.
- HTML, CSS, browser rendering, web performance, and server-side rendering (SSR).
- Large-scale web applications, telemetry, A/B experimentation, accessibility standards.
- LLM/AI-powered product features (streaming experiences), cross-platform/mobile hosts, live-site operations/monitoring/on-call, search/information retrieval concepts.
