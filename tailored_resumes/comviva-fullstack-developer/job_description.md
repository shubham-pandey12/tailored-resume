## Key Accountabilities

- Design, develop, test, and maintain scalable full stack web applications across frontend and backend layers
- Build responsive, user-friendly, and high-performance web applications aligned with business and technical requirements
- Develop and maintain frontend components, reusable UI modules, and backend services using modern frameworks and technologies
- Design, build, enhance, and optimize RESTful APIs and microservices to support application functionality
- Integrate frontend applications with backend services, databases, enterprise systems, and third-party APIs
- Ensure seamless user experience through efficient application design, performance optimization, and cross-browser compatibility
- Develop secure, reliable, and scalable solutions following industry best practices
- Collaborate with UI/UX designers to implement intuitive and accessible user interfaces
- Monitor, troubleshoot, and resolve application issues across frontend, backend, and integration layers
- Optimize application performance, service response times, frontend rendering, and database interactions
- Write clean, maintainable, and reusable code adhering to coding standards and guidelines
- Participate in code reviews, testing, and quality assurance activities
- Collaborate with BAs, architects, QA teams, product owners, and other stakeholders
- Participate in Agile ceremonies: sprint planning, daily stand-ups, backlog grooming, reviews, retrospectives
- Maintain technical documentation for architecture, APIs, integrations, components, and deployment
- Provide regular updates on development progress, risks, and dependencies
