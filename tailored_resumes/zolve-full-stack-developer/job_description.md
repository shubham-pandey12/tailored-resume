## Job Roles & Responsibilities

- Build and improve responsive **React** and **TypeScript** applications, including internal portals, landing pages, and customer-facing product workflows.
- Develop and maintain **Node.js** backend services using **NestJS** or **Express**, integrating APIs, databases, and frontend experiences into dependable end-to-end features.
- Own small modules and new features through design, implementation, testing, debugging, release, and production support.
- Investigate and fix application defects across user interfaces, backend services, data flows, and **third-party integrations**.
- Collaborate with product, design, and engineering stakeholders to clarify requirements, make practical technical decisions, and ship within short delivery cycles.
- Contribute to **code reviews**, engineering quality, **maintainability**, and basic **system-design** decisions across the application stack.

## Ideal Candidate Profile

- **3–5 years** of hands-on full-stack software development experience with independent ownership of production features.
- Strong **React** and **TypeScript** experience, including **component design, state management, API integration, debugging, and frontend performance**.
- Practical **Node.js** backend depth using **NestJS** or **Express**, with evidence of API development, database work, **validation, error handling, and service maintenance**.
- Working knowledge of **relational databases** (**SQL, Oracle Database**), **data modelling**, **testing**, **version control**, and **production troubleshooting**.
- Sound programming fundamentals and ability to solve basic **data-structure and algorithm** problems during evaluation.
- Clear communication and ability to explain past projects, design choices, trade-offs, and personal contribution.
- Based in India, with **Bangalore preferred**; remote work within India is also eligible.
- **Python** or **Django** experience is useful but not required.
