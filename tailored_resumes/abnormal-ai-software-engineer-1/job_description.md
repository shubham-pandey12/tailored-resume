## About the Role

Enterprises of all sizes trust Abnormal's AI-native security products to stop cybercrime and protect critical communications, identities, and infrastructure in the cloud. As a Software Engineer I on the MSP team in Bengaluru, you will help build and run new email security products from the ground up. This is a hands-on, full-stack role with a strong backend focus.

## Key Responsibilities

- Build and ship features across the stack (mostly backend services and APIs, some UI)
- Take over projects and drive them end to end — clarify requirements, write code, validate in test and production
- Build data and state handling: gather data from the core platform, run scheduled and background jobs
- Keep what you ship reliable — fix bugs, bottlenecks, add tests and monitoring, help debug production issues
- Work with Product, security, customer-facing teams, and other engineering teams
- Use AI tools throughout the development loop and validate AI-generated output
- Spot gaps in workflow/tooling/product, raise them, and prototype fixes
- Share knowledge through documentation, runbooks, code reviews, and project write-ups

## Must-Have Skills

- ~2 years professional software engineering, B.Tech in CS or related field
- Full-stack experience with clear backend lean
- Backend development in **Python and/or Go**, including REST APIs
- Working knowledge of relational databases
- Cloud platform (AWS, GCP, or Azure) + containers (Docker) + Kubernetes exposure
- CS fundamentals: data structures, algorithms, distributed systems basics, clean testable code
- Production observability: logging, metrics, alerting, debugging live systems
- AI development tools: Cursor, Copilot, Claude
- Initiative — built a small solution without being asked (internal tool, dashboard, automation)
- Ownership — can drive a project to completion without close supervision

## Nice-to-Have Skills

- Workflow orchestration: Airflow, Temporal, DAG-based pipelines
- Messaging/queueing: Kafka, RabbitMQ, SQS, SNS
- Modern frontend framework: React
