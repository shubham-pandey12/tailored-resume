## Key Responsibilities

### Backend & Microservices Development
- **API Architecture:** Build and optimize high-performance RESTful APIs, microservices, and gRPC backend channels using **Python** and **C# .NET**.
- **Database Management:** Design, administer, and optimize relational databases (**SQL Server, MySQL, PostgreSQL**) and NoSQL/Document databases (**MongoDB**).
- **System Integration:** Develop modular, secure web applications following company-wide cybersecurity and engineering frameworks.

### Frontend & UI Engineering
- **User Interface:** Create modern, responsive, and reusable web UI applications utilizing **ReactJS**, **JavaScript/TypeScript**, and **modern CSS frameworks**.
- **State & Connectivity:** Implement seamless **data binding** and front-end integration with back-end **RPC web services**.

### AI/ML & Generative AI Integration
- **Intelligent Solutions:** Implement functional AI/ML components leveraging **Large Language Models (LLMs)**, **Retrieval-Augmented Generation (RAG)** architectures, and **AI agents**.
- **Copilot Utilization:** Apply **prompt engineering** and generative technologies to augment core product features and workflows.
