## Summary
Information Systems and Technology (IS&T) — Customer Systems, powering Apple's customer support experience including contact center operations, Genius Bar software, and AppleCare's online support platform (6 billion visits per year).

## Responsibilities
- Design, develop, test, and maintain responsive and scalable web applications using modern frontend technologies.
- Translate product requirements, UX designs, and technical specifications into high-quality, reusable frontend components.
- Develop clean, modular, and maintainable code using modern UI frontend frameworks (Vue, Angular, React).
- Build reusable UI components and contribute to frontend component libraries and design systems.
- Collaborate closely with backend engineers to integrate RESTful APIs and other data services.
- Optimize web applications for performance, responsiveness, scalability, and cross-browser compatibility.
- Own frontend features end-to-end from concept, implementation, testing, debugging, deployment, and production support.

## Minimum Qualifications
- Bachelor's degree in Computer Science, Software Engineering, or a related field, or equivalent practical experience.
- 4+ years of professional experience in frontend/web application development.
- Hands-on experience with JavaScript, TypeScript, HTML5, and CSS3.
- Experience with modern frontend frameworks, such as Vue, Angular, React.
- Experience building responsive, accessible, and user-centric web applications.

## Preferred Qualifications
- Developing reusable UI components and implementing frontend design patterns.
- Integrating RESTful APIs and working with backend services.
- Frontend state management frameworks such as Redux or equivalent.
- Frontend build and development tools such as Webpack, Rush, ESLint, and related tooling.
- CI/CD pipelines and automated frontend build and deployment processes.
- Web performance monitoring, profiling, and optimization.
- Modern testing frameworks and tools such as Jest, React Testing Library, Cypress, or Playwright.
