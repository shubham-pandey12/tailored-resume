## Gap Mitigation Strategy

### Django
- **Gap size:** Medium. Python is in the skill set; Django follows familiar MVC/ORM patterns that map to Express.js.
- **Mitigation:** Frame Node.js/NestJS backend experience as equivalent depth. If asked in interview, be honest: "No Django production history, but I understand the framework and can demonstrate proficiency in a trial project within days."

### GCP
- **Gap size:** Small. AWS experience covers equivalent services (Compute, Storage, Container hosting).
- **Mitigation:** Cloud-agnostic architecture principles apply across providers. Ramp-up on GCP specifics (Cloud Run, Pub/Sub, BigQuery) is well-documented.

### WebSockets
- **Gap size:** Small. Built WebSocket-based streaming in a side project; pattern is well understood.
- **Mitigation:** Mention the AI Code Review Tool project (WebSocket streaming responses) in interviews.

### Snowflake
- **Gap size:** Small for this role (nice-to-have, not required).
- **Mitigation:** Do not over-flag. If asked, note familiarity with data warehouse concepts and SQL.
