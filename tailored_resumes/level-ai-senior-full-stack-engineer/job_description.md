# Job Description — Level AI, Senior Full Stack Engineer

**Company:** Level AI  
**Role:** Senior Full Stack Engineer  
**Location:** Noida / Bengaluru, India  
**Prep Date:** October 29, 2026  

---

## About Level AI

Level AI was founded in 2019 and is a Series C startup headquartered in Mountain View, CA. The company is revolutionizing customer engagement through an AI-native platform that leverages large language models (LLMs) to extract actionable insights from customer interactions. Their products power agent-assist workflows and real-time AI-assisted customer service at enterprise scale.

---

## Role Overview

Level AI is hiring a Senior Full Stack Engineer to own end-to-end development of features and tools for Agent Assist workflows. The role involves building production-ready web interfaces for real-time, customer-facing AI products and integrating with cloud services and event-driven pipelines.

---

## Core Competencies Required

- **Backend:** Python (Django), Node.js (NestJS), TypeScript, REST APIs, GraphQL
- **Frontend:** React, JavaScript/TypeScript, HTML, CSS/SCSS, Redux, Ant Design
- **Data:** PostgreSQL/MySQL, MongoDB, Redis, Snowflake
- **Infrastructure:** GCP, Docker, Kubernetes, CI/CD
- **Other:** OOP, Data Structures & Algorithms, Caching, WebSockets, Multi-tenant systems, real-time AI-assisted workflows

---

## Responsibilities

- Own end-to-end development of features and tools for Agent Assist workflows
- Build web interfaces for real-time, customer-facing AI products
- Turn designs and wireframes into production-ready full-stack code
- Develop features using React and backend services such as Django and NestJS
- Build reusable components and shared front-end libraries
- Design and implement scalable APIs and service integrations
- Integrate with cloud services and event-driven pipelines to support real-time assistance

---

## Requirements

### Required
- Education: B.E/B.Tech/M.E/M.Tech from Tier-1 engineering institutes
- Experience: 3-5 years of full-stack development
- 2+ years of web application development
- Strong proficiency in JavaScript/TypeScript, HTML, and CSS
- Solid understanding of React and its ecosystem (Redux, hooks, component patterns)
- Experience with backend frameworks: Django, Node.js, or NestJS
- Experience with relational databases: PostgreSQL or MySQL
- Experience with MongoDB or other NoSQL databases
- Experience with Redis or similar caching systems
- Strong product sense and ability to build reliable, user-focused enterprise applications

### Nice To Have
- Experience with GraphQL
- Experience with Docker and Kubernetes
- Experience with GCP services
- Experience with Snowflake or other data warehouses
- Experience with WebSockets and real-time features
