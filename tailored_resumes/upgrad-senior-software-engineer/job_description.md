## Role Summary

"A frontend engineer who thinks beyond the frontend." Backend-aware, performance-obsessed Senior Engineer owning the web experience end-to-end — Core Web Vitals, Next.js rendering strategies, CDN/caching, browser profiling, and reusable frontend foundations.

---

## What You'll Do

- Own the web experience — Next.js, TypeScript, JavaScript, strong engineering foundations
- Own web performance — Core Web Vitals (LCP, INP, CLS, TTFB), rendering strategies, hydration, caching, resource loading
- Measure, don't guess — browser profiling, Lighthouse, RUM, observability/profiling tools, real-user performance
- Think beyond components — CDN/caching → server rendering → APIs → browser execution → user experience
- Design for scale — reusable frontend foundations and patterns that grow across products and teams
- Think from first principles — question assumptions, understand trade-offs
- Think product, not tickets — own how the experience works, performs, and feels
- Keep it lean — challenge unnecessary dependencies, excessive JavaScript, expensive rendering
- Be cross-functional — backend, infrastructure, design, product collaboration
- Move with pace — build, ship, measure, learn, improve
