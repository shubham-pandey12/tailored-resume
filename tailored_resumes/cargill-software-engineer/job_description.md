# Job Description — Cargill Software Engineer (Full Stack MERN)

**Company:** Cargill
**Role:** Professional, Application Development – Full Stack (MERN) / Software Engineer
**Location:** Bengaluru, Karnataka, India
**Prep Date:** October 29, 2026

---

## Job Purpose

The Professional, Application Development – Full Stack (MERN) role designs, develops, and deploys scalable web applications using ReactJS, NodeJS/Express, PostgreSQL, and AWS Cloud. Delivers secure, high-performing, cloud-native solutions with strong focus on dynamic programming, clean architecture, and DevOps best practices.

---

## Key Accountabilities

### Cloud & DevOps
- Deploy and manage applications on AWS.
- Build and maintain CI/CD pipelines.
- Use Docker for containerized deployments.

### Application Development
- Build responsive front-end applications using ReactJS.
- Build scalable back-end services using NodeJS/Express.
- Design REST APIs, optimize databases, and implement efficient algorithms.

### Configuration & Security
- Manage environments, authentication, integrations.
- Ensure adherence to security standards.

### Testing & Quality
- Develop unit and integration tests using Jest or Mocha.
- Nice to have: experience with end-to-end automated testing tools such as Cypress or Playwright.
- Conduct code reviews and maintain high coding standards.

### Support & Incident Management
- Troubleshoot issues, optimize performance.
- Prioritize incidents to meet SLA commitments.

### Stakeholder Collaboration
- Work with global teams to align technical solutions with business goals.
- Communicate effectively across distributed teams.

### AI-Enabled Development
- Utilize AI code assistants to improve development efficiency and code quality.

---

## Required Stack (MERN Focus)

- **ReactJS** — frontend
- **NodeJS/Express** — backend
- **PostgreSQL** — primary database
- **AWS Cloud** — deployment and management
- **Docker** — containerization
- **CI/CD pipelines**
- **REST APIs**
- **Jest or Mocha** — testing
- **Security standards**

---

## Nice to Have

- Cypress or Playwright (E2E testing)
- AI code assistants (ChatGPT, GitHub Copilot, Claude)
- MongoDB (NoSQL)

---

## Qualifications

- Minimum 2 years of relevant work experience, typically 3+ years
- Strong knowledge of full-stack web development
- Experience with cloud-native architectures and DevOps practices
