4. **Postgres Internals:** Master uses SQL/MySQL/MongoDB/Redis rather than Postgres specifically. Review Postgres MVCC, vacuuming, indexing (B-tree/GIN/BRIN), partitioning, and connection pooling.
5. **Golang / Python Production Depth:** Master `resume.tex` shows primary backend execution in Node.js/Express (though `Python` is in Skills Summary). Be ready to code cleanly in Python or Golang (concurrency, error handling, memory/profiling) in live technical rounds.
6. **Threat Intelligence / Cybersecurity Domain:** Exposure is limited to WebHealth passive security scanning and OAuth; prepare on email security signals, IOCs, and high-throughput threat telemetry pipelines.
