# Job Description — BNY Senior Associate, Full-Stack Engineer

**Company:** BNY (BNY Mellon)
**Role:** Senior Associate, Full-Stack Engineer
**Location:** Pune / Pimpri-Chinchwad Area
**Prep Date:** October 29, 2026

---

## About BNY

BNY is a global financial services company influencing nearly 20% of the world's investible assets. Recognized on Fortune's America's Most Innovative Companies 2025 and World's Most Admired Companies 2025 lists. BNY is committed to delivering innovative, technology-driven solutions to the financial services industry.

---

## Role Overview

Uses existing and emerging technology platforms to design, develop, and document technically detailed applications. Writes new complex systems, designs and codes programs, and creates test transactions. Analyzes organizational needs and goals to develop and implement application systems. Provides application software development services or technical support in situations of moderate complexity. May also be responsible for requirements gathering and BRD/SRD preparation. Has thorough knowledge of the Software Development Life Cycle. Conducts reviews of the test plan and test data.

---

## Key Responsibilities

- Programming well-designed, testable, efficient code
- Analyze, design and develop tests and test-automation suites
- Develop flowcharts, layouts and documentation to satisfy requirements
- Maintain software functionality and currency (technical debt and gain)
- Actively participate in code reviews
- Integrate software components into a fully functional software system
- Apply security and privacy principles
- Execute full lifecycle software development
- Develop software verification plans and quality assurance procedures
- Troubleshoot, debug and upgrade existing systems
- Ensure software is updated with latest features
- Participate in deployment process following all change controls
- Provide ongoing maintenance, support and enhancements in existing systems
- Provide recommendations for continuous improvement
- Active learning engagement, use of Pluralsight
- Demonstrate teamwork; leverage existing products/functionality
- Collaborate cross-functionally with data engineers, business users, project managers
