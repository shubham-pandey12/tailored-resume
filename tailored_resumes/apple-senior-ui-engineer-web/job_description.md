## Description

We are seeking a Senior UI Engineer who is passionate about crafting visually stunning web applications that embody the highest standards of design, usability, and engineering excellence.

The role calls for an engineer deeply committed to building high-performance, accessible, scalable, and innovative web experiences that continually delight and inspire customers around the world. With a strong eye for pixel-perfect detail and a passion for exceptional user experience, you will turn requirements, user journeys, and wireframes into intuitive, production-ready applications.

You will also have opportunities to leverage Generative AI and AI-assisted development to accelerate engineering workflows, rapidly prototype ideas, improve productivity, and build innovative AI-powered user experiences.

---

## Responsibilities

- **Application Architecture & UI Craft:** Architect, build, and maintain scalable, high-performance web applications using modern JavaScript/TypeScript and frameworks (React, Angular, or Vue), transforming wireframes and designs into pixel-perfect, responsive user experiences.
- **Design Systems & Token Architecture:** Design and scale reusable component libraries and enterprise design token systems (typography, color, spacing, theming) to drive visual consistency and development velocity across large applications.
- **Performance & Core Web Vitals:** Proactively measure, monitor, and enforce production performance budgets — optimizing Core Web Vitals (LCP, CLS, INP), rendering pipelines, bundle sizes, lazy loading, and asset caching.
- **Accessibility & Inclusive Design:** Champion WCAG accessibility standards and inclusive design best practices, ensuring cross-browser compatibility and seamless usability across all devices.
- **Data Layer & API Integration:** Connect front-end clients with RESTful and GraphQL backend services, efficiently managing asynchronous state, data streaming, and large, complex datasets.
- **Engineering Rigor & Quality:** Write comprehensive automated tests (unit, integration, and E2E), lead constructive code and design reviews, and actively improve developer tooling, automation, and CI/CD workflows.
- **AI-Assisted Developer Productivity:** Leverage Generative AI tools to accelerate prototyping, coding, testing, and debugging workflows, applying rigorous engineering judgment to validate AI-generated code for security, privacy, and correctness.
- **AI-Powered Product Experiences:** Integrate applications with LLM APIs, services, and agentic workflows to build innovative, contextual user experiences (e.g., conversational interfaces, semantic search, and intelligent recommendations).
- **Cross-Functional Collaboration & Ownership:** Partner closely with UX designers, product managers, and backend engineers to influence technical solutions and deliver end-to-end features with high autonomy.

## Minimum Qualifications

- 4–8 years of professional front-end engineering experience building large-scale consumer- or enterprise-facing web applications
- Deep hands-on expertise in modern JavaScript (ES6+), TypeScript, semantic HTML5, and advanced CSS3
- Practical experience using Generative AI tools such as ChatGPT, GitHub Copilot, Claude, or equivalent
- Experience integrating an application with an LLM or AI-powered API (strong plus)
- Proven track record architecting scalable applications using React, Angular, or Vue with robust state management (Redux, MobX, Context API, NgRx, or equivalent)
- Strong experience building and contributing to reusable component libraries or design systems; relentless eye for responsive design and pixel-perfect implementation
- Demonstrated expertise in front-end performance profiling and optimization: code splitting, lazy loading, rendering efficiency, caching strategies, bundle minimization
- In-depth understanding of cross-browser compatibility, modern web standards, and WCAG/WAI-ARIA accessibility compliance
- Practical experience integrating RESTful and GraphQL APIs, managing asynchronous data flows, and handling complex or large-scale front-end datasets
- Proficiency in front-end automated testing frameworks (Jest, Playwright, Cypress, or Testing Library), modern Git workflows, and Agile delivery practices
