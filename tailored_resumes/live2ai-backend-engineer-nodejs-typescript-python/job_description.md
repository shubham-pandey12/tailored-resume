## Requirements

- Minimum 3 years of experience building and operating production backend services.
- Strong relational data modelling skills, including multi-tenant or access-scoped designs.
- Solid understanding of asynchronous processing, background workers, queues, and how to handle partial failures.
- Experience designing and versioning APIs for consumers whose systems cannot be changed at the same time as yours.
- Experience taking responsibility for production correctness, including data integrity, access isolation, and operational issues.

**Backend Stack:**
- Languages: Python and TypeScript
- APIs and services: FastAPI and Node.js
- Data: PostgreSQL and Redis
- Asynchronous processing: Celery, message queues, and background workers
- Infrastructure: AWS, Docker, and Kubernetes
- Observability: OpenTelemetry, Prometheus, and Grafana
- CI/CD: GitHub Actions
- Architecture: Multi-tenant services, event-driven processing, and REST APIs

**Nice to have:**
- Regulated/audited domain experience, real-time or streaming systems, working across multiple languages, improving performance in data-heavy systems, enterprise integrations.

## Responsibilities

- Build and operate backend services with strict data integrity and isolation requirements.
- Design data models for multi-tenant systems and maintain their correctness under delivery pressure.
- Build asynchronous and queue-based processing that handles failures midway through a workflow.
- Design and maintain APIs used by internal teams and enterprise customers.
- Version APIs carefully to protect existing integrations.
- Own services after deployment, including production issues and on-call responsibilities.
