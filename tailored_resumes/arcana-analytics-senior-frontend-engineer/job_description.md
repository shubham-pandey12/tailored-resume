## About Arcana Analytics

Arcana Analytics is a cutting-edge technology company building data analytics infrastructure and products. The team is at the forefront of compute and I/O-intensive application development.

---

## Role Overview

Senior Frontend Engineer in a pivotal role building innovative, user-centric web interfaces for compute and I/O-intensive applications. The role spans React frontend architecture, backend API server development, performance optimization, and system scalability. Deep CS fundamentals, system design expertise, and product development experience are core requirements.

| Area | Description |
|---|---|
| Front-End Excellence | Deep React expertise — architect and build innovative, user-centric web interfaces |

## Requirements

- Bachelor's degree in CS, Computer Engineering, or equivalent
- At least **3 years** of experience with modern frontend and backend systems
- Solid background in **object-oriented software development**
- Advanced skills in **HTML, CSS, JS, and React**
- Interest in exploring new technologies; creative freedom to propose innovative solutions
- Previous product development experience or strong desire to understand the holistic product vision
- Deep CS fundamentals: data structures, algorithms, system design
