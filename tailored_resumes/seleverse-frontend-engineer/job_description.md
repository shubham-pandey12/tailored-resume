## Summary

Build the interfaces that millions of African creators and journalists will use daily. You will own the frontend experience of SeleVerse — from the Griot Feed to the Creator Dashboard.

## Responsibilities

- Build and maintain high-performance React/Next.js components
- Collaborate with design to implement pixel-perfect, accessible UIs
- Optimize for performance across low-bandwidth African networks
- Integrate with Sele AI APIs for real-time content features
- Write clean, tested, documented code

## Requirements

- Strong portfolio of shipped web products — show us what you have built
- Deep knowledge of React, TypeScript, and modern CSS
- Experience with performance optimization for emerging markets
- Understanding of accessibility standards
- No degree required — your work speaks for itself

## Nice to Have

- Experience with Next.js App Router
- Familiarity with African languages and RTL text
- Open source contributions
