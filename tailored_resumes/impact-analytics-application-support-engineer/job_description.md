## What This Role Entails

### Production & Application Support
- Monitor backend applications, services, APIs, databases, queues, and critical production systems
- Provide L2 and L3 production support; respond to incidents within defined SLAs
- Troubleshoot application failures, performance issues, API errors, data issues, service disruptions
- Initial investigation, log analysis, issue triaging before escalating to engineering
- Identify recurring production issues; work with dev teams on permanent fixes

### Incident Management
- Respond to production alerts and incidents during assigned shifts
- Own incidents from identification through investigation, mitigation, resolution, and closure
- Coordinate with Development, DevOps/SRE, QA, Database, and Infrastructure teams
- Escalate based on severity levels; maintain stakeholder communication
- Participate in Root Cause Analysis (RCA) and post-incident reviews

### Monitoring & Observability
- Monitor system health, application performance, availability, and error rates
- Analyze application logs, metrics, traces, and alerts
- Help improve alerting mechanisms; reduce false positives
- Monitor scheduled jobs, batch processes, data pipelines, and integrations

### Operational Excellence
- Create and maintain runbooks, SOPs, troubleshooting guides, knowledge-base docs
- Regular health checks and operational activities
- Identify automation opportunities to reduce manual support effort
- Support release activities; monitor applications after production deployments
- Ensure proper shift handovers

### Continuous Improvement
- Analyze recurring incidents and operational trends
- Work with engineering to improve stability, reliability, performance
- Recommend improvements to monitoring, logging, alerting, automation
- Contribute to reducing MTTR and improving service availability
