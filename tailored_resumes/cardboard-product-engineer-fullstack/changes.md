# Cardboard resume changes and verification
Prepared October 25, 2026.

## Scope and sources
Created a new application folder; original resume.tex is the sole factual baseline. Reviewed the root workflow, baseline, older Cardboard draft, and a recent Syfe source/cover letter/change report for conventions. Other existing files were inventoried but not exhaustively reviewed. No claims were imported from tailored drafts.

## Changes
- Put fullstack ownership, AI applications, and measured product/performance outcomes first.
- Ordered sections: Summary, Work Experience, Projects, Skills Summary, Education, Achievements.
- Retained employer names, titles, dates, locations, contact information and links, degree, award and supported metrics.
- Condensed supporting skills and project details for a readable one-page application.
- Added a matching cover letter, requirement matrix and screening drafts; no application was sent.

## Parsing and layout
Original uses tabular headings and contact layout, custom heading macros, an unsupported 20pt article option, negative spacing, and small-font helper macros. The tailored version uses standard 10pt article, 0.55-inch margins, visible contacts and ordinary sequential text headings; no tables, icons, columns or hidden keywords. No fontawesome macros, hidden layers or ligature-manipulation packages were found in the baseline. Unused symbol/template packages were not retained.

- Extracted resume text into resume.txt; assertions verify contacts, all employers and dates, degree, impact metrics, key terms and section order. Checked no replacement glyphs, duplicate employer text, or out-of-margin text.
- Verified original files and all files captured in the initial preservation manifest remained byte-for-byte unchanged.

## Limits

Application answers flag metric methodology, daily coding-agent use, user research/product prioritization examples, availability, work authorization, location preferences and compensation for your confirmation.
